# Profile Structure & Section Blueprint

This document details the exact 18-section structural sequence of **Nguyễn Bá Sơn**'s GitHub profile README.

---

## 18-Section Order Index

| # | Section Name | Layout Alignment | Core Widgets / Content | Purpose |
| :-: | :--- | :-: | :--- | :--- |
| **1** | **Banner** | Center | Custom Cyber-Glassmorphism `assets/banner.png` | Visual hero section establishing immediate brand identity. |
| **2** | **Typing SVG** | Center | `readme-typing-svg.demolab.com` | Dynamic introduction highlighting roles & core skills. |
| **3** | **Social Links** | Center | `img.shields.io` Badges | Quick contact shortcuts for recruiters & collaborators. |
| **4** | **Profile Views** | Center | `komarev.com/ghpvc` | Live traffic metrics badge. |
| **5** | **About Me** | Left | Formatted Markdown + Code Block | Technical summary, institution background, and focus areas. |
| **6** | **Tech Stack** | Left | `skillicons.dev` Icons | Organized breakdown of Frontend, Backend, DB & Tools. |
| **7** | **Featured Projects** | Left | Detailed Markdown Cards + Repo Link | Highlights top 4 full-stack projects with features & tech. |
| **8** | **GitHub Stats** | Center | `github-readme-stats.vercel.app` | Overall commits, stars, PRs, and contribution grade. |
| **9** | **Top Languages** | Center | `github-readme-stats.vercel.app/api/top-langs` | Visual breakdown of language usage distribution. |
| **10** | **GitHub Streak** | Center | `github-readme-streak-stats.herokuapp.com` | Continuous commit streak tracker. |
| **11** | **Activity Graph** | Center | `github-readme-activity-graph.vercel.app` | 31-day activity frequency visualization curve. |
| **12** | **Profile Summary Cards** | Center | `github-profile-summary-cards.vercel.app` | Repository & commit detail breakdown cards. |
| **13** | **GitHub Trophy** | Center | `github-profile-trophy.vercel.app` | Achievement trophies derived from GitHub activities. |
| **14** | **WakaTime** | Center | `github-readme-stats.vercel.app/api/wakatime` | Coding time metrics tracking development hours. |
| **15** | **Contribution Snake** | Center | `Platane/snk` SVG Animation | Interactive snake animation consuming contribution grid. |
| **16** | **Currently Learning** | Left | Categorized Bullet Points | Highlights active technology mastery targets (Docker, Cloud, etc.). |
| **17** | **Career Goals** | Left / Center | Blockquote Statement | Formal long-term career ambition statement. |
| **18** | **Contact** | Center | Shields & Email Direct Link | Recruiter outreach footer with professional contact channels. |

---

## Maintenance & Workflows

1. **Snake Animation Workflow:** Automatically runs daily via `.github/workflows/snake.yml` and pushes to `output` branch.
2. **Metrics Generation:** Configured via `.github/workflows/metrics.yml` and runs automatically.
3. **Summary Cards Generator:** Configured via `.github/workflows/profile-summary.yml` running daily.
