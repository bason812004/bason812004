## 4. Repository Best Practices Checklist for Candidates

To maintain a top-tier GitHub profile, ensure the following practices across individual project repositories:

- [x] **Root README.md for every repo:** Include architecture diagrams, setup instructions, environment variables template, and live demo links.
- [x] **Clean Commit Messages:** Follow standard Conventional Commits (`feat: ...`, `fix: ...`, `docs: ...`, `refactor: ...`).
- [x] **Topic Tags:** Add relevant GitHub repository tags (e.g., `react`, `typescript`, `nodejs`, `postgresql`, `prisma`, `fullstack`).
- [x] **No Leaked Credentials:** Ensure `.env` is ignored and zero secrets/API keys are exposed.
- [x] **Production Deployment:** Host live demos on Vercel/Render/Supabase and link them in repo headers.
